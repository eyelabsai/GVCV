# AEO Citation Audit — ICL prompt set

**Purpose:** find out which URLs the AI engines cite when answering ICL questions, so we get a
*named* off-site target list (which Reddit threads / articles / sites to engage) instead of a vague
"do off-site work" backlog. This is the one reverse-engineering step we haven't run. See `AEO-STATUS.md`.

## How to run (free, ~45 min, repeat monthly)

1. **Logged OUT** (or incognito / memory off) — otherwise ChatGPT personalizes and you measure yourself, not the public web.
2. Run each prompt in engines that actually retrieve: **ChatGPT (search on), Perplexity, Google AI Mode, Google AI Overviews, Gemini**. (Skip vanilla no-search chat — that's training data, not citations.)
3. For each answer log: **(a) which brands/experts are named, (b) every URL cited.** The URLs matter most.
4. Tally the URLs. The domains/threads that keep feeding answers = your off-site target list.
5. Note where **icl.fit / iclsurgery.com / gurpalvirdi.com / Virdi / Hirabayashi / VAULT** appear (or don't).

> Non-deterministic — one run isn't a measurement. Same prompts, monthly, watch the trend.
